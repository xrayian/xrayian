## 📌 Executive Summary

I am a Dhaka-based **Full-Stack and Mobile Developer** and **B.Sc. CSE undergraduate at United International University (UIU)**, currently serving as **Director of Innovation at Prologic Software / Projucti**. 

Building software since **2019**, I specialize in:
- ⚡ **Realtime & Multiplayer Architectures**: Authoritative state synchronization, Colyseus game rooms, WebRTC, and Mediasoup media routing.
- 📱 **Cross-Platform Mobile Engineering**: Production-ready Flutter and React Native applications serving enterprise and local ecosystems.
- 🤖 **AI-Enabled Multimodal Pipelines**: Asynchronous queued workflows, LLM orchestration (Gemini, Ollama), voice synthesis (ElevenLabs), and object storage.
- 🛰️ **Hardware & IoT Telemetry**: Sensor integration with ESP8266/ESP32, MQTT pub/sub pipelines, and aerospace flight-software integration.
- 🧪 **Software Quality & Testing**: Rigorous test suites (100–250+ automated unit, integration, and security tests) ensuring robust deployments.

### 1. [Digital Sheriff of Nottingham](https://github.com/xrayian/digital-sheriff-of-nottingham)
> **Authoritative Realtime Multiplayer Board Game (3–6 Players)**

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![Colyseus](https://img.shields.io/badge/Colyseus-Realtime_Server-orange?style=flat-square)

![Tests](https://img.shields.io/badge/Tests-114_Passing-brightgreen?style=flat-square)

- **Architecture:** Server-authoritative state engine using Colyseus and schema-based state sync to guarantee hidden-hand privacy and prevent client-side tampering.
- **Client & Audio:** Reactive client built with Vite, Tailwind CSS, Framer Motion, and procedural Web Audio effects.
- **Verification:** Backed by **114 automated tests** covering game logic, room state, concurrency, and security rules.
- **DevOps:** Fully containerized with Docker, Nginx reverse proxy, and automated SSL orchestration.
